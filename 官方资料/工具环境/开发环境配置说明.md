# 开发环境配置说明

## Keil MDK 安装

凌霄飞控源码使用 Keil MDK 开发。

### 本地安装包

`tools/开发环境安装/` 目录包含：
- Keil.MDK 5.14 破解版
- Keil.STM32F4xx_DFP.2.2.0.pack（213MB，STM32F4 设备支持包）
- Keil.TM4C_DFP.1.0.3.pack（TM4C 设备支持包）
- 安装教程 PDF

### 支持的 MCU

凌霄飞控源码支持三种 MCU 平台：
- **STM32F407**（推荐）
- **MSP432P401**
- **TM4C123**

### 工程文件位置

各平台工程文件位于：
- `firmware/ANO_LX_FC/ProjectSTM32F407/ANO_LX_STM32F407.uvprojx`
- `firmware/ANO_LX_FC/ProjectMSP432/ANO_LX_MSP432.uvprojx`
- `firmware/ANO_LX_FC/ProjectTM4C123/ANO_LX_TM4C123.uvprojx`

## 匿名上位机

用于飞控参数配置、姿态显示、数据记录。

### 本地文件

`tools/匿名上位机/` 目录包含下载地址说明。

### 通信协议

详见 `docs/01-用户手册与通信协议/匿名通信协议V7.pdf`

## Python SDK

部分参考工程包含 Python 上位机代码，用于任务规划和数据交互。

### 依赖安装

```bash
pip install pyserial numpy opencv-python
```

### 示例位置

- `firmware/2022-HUST/python_sdk/`
