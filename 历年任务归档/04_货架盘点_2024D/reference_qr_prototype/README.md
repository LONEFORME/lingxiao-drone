# 二维码/云台原型快照

来源（2026-07-18）：

`/home/sunrise/Desktop/视觉测试/二维码/`

该目录保留 notebook、二维码映射和原型 Python 代码，便于后续逐项适配。它不是
比赛运行模块，原因包括：

- 首个单帧识别结果就会接受并触发激光；
- 激光脉冲默认 1.0 秒且阻塞当前识别循环；
- 舵机按已识别唯一编号数量每 6 个自动翻转，可能与物理货架面失步；
- 没有货位状态、二维码框瞄准、多帧一致性和飞行日志关联；
- 依赖 IPython notebook 显示，不适合无界面比赛进程。

可复用部分是摄像头低缓冲取流、二维码映射格式、sysfs PWM 舵机适配器和 BCM19
激光驱动思路。正式模块应把云台和激光的控制权交给任务状态机。
