## 🚀 新手快速入门 SOP（从零到首飞）

### 步骤 1：开发环境搭建
1. 打开 `tools-env/开发环境配置说明.md`；
2. 安装 Keil MDK 5；
3. 安装 STM32F4xx DFP 设备支持包（或 TI 对应芯片包）；
4. 安装 J-Link 驱动并验证 SWD 下载器连通性（参考 `tools-env/驱动安装说明.md`）。

### 步骤 2：阅读飞控手册与硬件接线
1. 查阅 `docs/01-用户手册与通信协议/匿名--凌霄到手飞手册.pdf` 了解基础硬件接线；
2. 查阅 `docs/03-原理图与PCB/` 确认飞控主板供电口、串口 UART1~UART4、I2C 及 PWM 舵机输出端口。

### 步骤 3：编译与下载官方纯净固件
1. 双击打开 `firmware-baseline/ANO_LX_FC/ProjectSTM32F407/ANO_LX_STM32F407.uvprojx`；
2. 点击 Keil 的 `Rebuild` 进行编译（确保 0 Error）；
3. 使用 J-Link 连接飞控 SWD 接口，点击 `Download` 烧录。

### 步骤 4：运行入门基础例程
1. 参考 `examples/例程1.一键起飞_降落/`，将例程中的 `User_Task.c` 替换到工程；
2. 观察无人机一键解锁、平稳起飞至预设高度、悬停并自动平稳降落。

### 步骤 5：进阶自主系统开发
当掌握基础飞行后，请移步至根目录下的 **`drone-system/`（自研完整无人机实战系统）**，体验融合了双目空间定位与边缘视觉的高阶全自主无人机。
